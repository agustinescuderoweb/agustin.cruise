# Sitio personal · Viajes, networking y desarrollo personal

Proyecto Next.js (App Router) + Tailwind CSS + TypeScript.

## Ejecutar

```bash
npm install
npm run dev
```

Abrí http://localhost:3000

## Personalizar

- `app/page.tsx`: cambiar `WHATSAPP` por tu número real y `INSTAGRAM` por tu perfil elegido.
- Reemplazar el bloque visual del hero por tu foto/video cuando tengas los archivos.
- Editar el texto de presentación, mensajes y enlaces.
- `app/globals.css` y `tailwind.config.ts`: colores y estilos.

El contenido sobre inCruises diferencia membresía y actividad comercial, sin prometer ingresos ni beneficios no verificados.
